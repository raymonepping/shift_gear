    What this proves — and what it does not

    Proves

    • Vault KV v2 versions really change (the rotation add-on writes them).
    • A Vault Agent sidecar alone authenticates, reads and renders the latest version.
    • The running app notices, reloads without restarting, and stops using the old value.

    Does not prove

    • Issuer-side rotation: no external system issued or revoked anything.
    • That a real service rejects the old credential: the door is fictional.
    • Vault authorisation from the connectivity row: it shows reachability only.
